Все возможности

Полный функционал для управления автопарком

🚗

Учёт машин

Добавляйте автомобили, указывайте марку, номер, пробег и водителя. Полная история каждой машины.

👤

Штат водителей

Ведите учёт водителей: ФИО, телефон, категории прав (A, B, C, D, E). Удобный поиск и фильтрация.

⛽

Учёт заправок

Выбирайте тип топлива (АИ-92, АИ-95, АИ-98, ДТ, Газ). Стоимость рассчитывается автоматически.

📊

Статистика

Сводная информация по расходам, пробегу и количеству заправок. Все данные на одном экране.

🔧

График ТО

Отслеживайте следующее техническое обслуживание каждой машины. Прогресс-бар показывает состояние.

🔐

Регистрация

Создавайте аккаунт, входите в систему — данные сохраняются надёжно.

🗑

Массовое удаление

Отмечайте галочками ненужные записи и удаляйте их одним нажатием.

🌐

Веб-сайт

Связан с сайтом — открывайте информацию о проекте прямо из приложения.
