О проекте

Как создавалось приложение «Автопарк 24»

«Автопарк 24» — учебный проект мобильного приложения для управления корпоративным автопарком. Разработан на языке Java в среде Android Studio с использованием Material Design и современной архитектуры.

Цель проекта — показать, как с помощью простого приложения можно систематизировать работу с автопарком: вести учёт машин, водителей, заправок и технического обслуживания.

  • ✓ Разработка на Java + Android Studio
  • ✓ Тёмная тема и современный UI
  • ✓ Хранение данных в SharedPreferences
  • ✓ Регистрация и авторизация
  • ✓ Учёт машин, водителей и топлива
  • ✓ График ТО с прогресс-баром
  • ✓ Массовое удаление записей
  • ✓ Связка с веб-сайтом
